HOW IT THINKS
PLAYOUTS FILL THE BOARD
A random game is finished by shuffling the empty cells and alternating colours. Hex has no draws, so the full board has one winner, and one connectivity check decides the playout.
UCT TRUSTS ITS OWN WINS
Each move is scored by its win rate plus an exploration bonus. It needs many visits before the rate means much.
RAVE SHARES BETWEEN MOVES
A stone played anywhere below a node counts as if it had been played first there (AMAF). Early on, the shared estimate is blended in with weight beta = sqrt(k / (3n + k)), which fades as the move gets visits.
HEAT AND PRINCIPAL VARIATION
Heat shows where the search spent its visits, or the RAVE rate. The numbered line is the most-visited path from the root: the agent's expectation of how the game goes.

HOW IT WORKS

The agent is Monte Carlo tree search. From the current position it plays many random games to the end, keeps score of which first moves win, and plays the move it has visited most often. The default, RAVE, also counts a move's results from random games where that move came later, so it learns faster when the budget is small.

RAVE-MCTS (default)

New to this? Judging a dish from a few tasting plates is slow if you only count a dish when it is served first. RAVE also counts it whenever it turns up later in the meal, so every dish gets feedback sooner. The estimate is noisy, so as a dish is tasted more, its own record takes over.

Each simulation selects down the tree by score, adds one new move, finishes the game at random, and adds the result to every node on the path. A child's score blends its win rate with its RAVE rate: Q = (1 - beta) Q_uct + beta Q_rave, with beta = sqrt(k / (3n + k)), k = 300, and exploration constant c = 0.6. Expansion tries the untried move with the best RAVE rate first.

  • With the swap rule on, the agent's first turn as the second player runs two searches, one for staying and one for swapping, and swaps when its win chance is higher after swapping.
  • The move it plays is the most-visited child of the root.

Plain UCT

New to this? UCT is the rule "try the best option, but also check the ones you have barely tried". Each move's score is its win rate plus a bonus that is large for moves with few visits, so the search explores instead of fixating on an early favourite.

Its score is the win rate plus c * sqrt(ln N / n), with c = 0.6, where N is the parent's visits and n the child's. Untried moves are expanded in random order, and it uses no RAVE statistics.

  • On the 7×7 benchmark at 400 simulations per move, it wins 13 of 40 games against the shortest-path race.

Shortest-path race (baseline)

New to this? Hex is a race to connect. Count how many empty cells each side still needs to finish its chain, the way you would count the bricks left in a wall. Then play the cell that slows the opponent the most while speeding you up.

Distance is a 0-1 breadth-first search: your stones cost 0, empty cells cost 1, and opponent stones are walls. A move scores the opponent's distance minus your own, with random tie-breaks. It looks one move ahead only.

Random (baseline)

New to this? A random empty cell, chosen without any thought. It sets the floor for the others.

  • RAVE and UCT both beat it in all 40 benchmark games.

How these were chosen: c = 0.6 and k = 300 are constants in hexgame/mcts.py, set by hand and not tuned: the repository has no sweep over either. The beta formula is the RAVE blend from Gelly and Silver, as the code cites. Each level's budget caps the work per move at a simulation count or a time, whichever comes first, so one request stays bounded.

Results (7×7, 400 simulations per move, 40 seeded games per matchup, 95% Wilson intervals): RAVE beats UCT in 40 of 40 games, and it beats the shortest-path race in 39 of 40. UCT wins 13 of 40 against the race. Speed on an empty board, single core, pure Python: RAVE 5,811 simulations per second, UCT 5,783, random playouts 10,739 per second. A check at 1,000 simulations (20 games, recorded in the README but not in results/) has RAVE winning 18 of 20 against UCT, so the gap narrows with budget. That is not a measured reversal.

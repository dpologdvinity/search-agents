HAND-TUNED VS LEARNED
The hand-crafted agent scores boards with six features (empty cells, monotonicity, corner, merges, smoothness, max tile), with weights found by an automated search over simulated games. The n-tuple network learned its own scoring from 42,980 self-played games.
CHANCE NODES
After each move a 2 (90%) or 4 (10%) appears in a random empty cell. Expectiminimax averages over every possibility, so the value shown is an expectation, not a guarantee.

HOW IT WORKS

The agents look a few moves ahead, averaging over the random tile that appears after each slide. One scores positions with six hand-chosen features whose weights were found by an automated search. The other is an n-tuple network: a table of values for small patches of the board, learned by playing games. The third combines the table with the same look-ahead.

Expectimax (tuned features)

New to this? Planning a route when some roads may be closed at random: for each choice, weigh every way the randomness could turn out by how likely it is, and pick the choice with the best average result.

Alternates player nodes, which choose a slide, with chance nodes, where a 2 (probability 0.9) or a 4 (probability 0.1) appears in each empty cell with equal chance. Iterative deepening runs up to depth 20 within 0.1 s per move. Leaves are scored by the tuned evaluation below.

N-tuple network (no search)

New to this? A cheat sheet that lists a score for every small patch of a board. To judge a position, look up each patch and add the scores, with no planning at all.

Six 5-cell patterns, each with its own table of 16⁵ = 1,048,576 values. Each pattern is read under the 8 board symmetries, so a position costs 48 lookups. The move chosen maximises points gained plus the value of the resulting board. Trained by TD(0), below.

N-tuple + expectimax

New to this? Use the cheat sheet to judge positions at the end of a short look-ahead, so the planning and the table work together.

The expectimax search above, with the n-tuple value plus points gained along the line used as the leaf score. It is the default when the table is available.

How these were chosen: tuned automatically with the cross-entropy method (game2048/tune.py). Each generation draws candidate weight vectors from a Gaussian, scores each by the mean final score of greedy one-move-lookahead games on shared seeds, keeps the best elite, and refits the Gaussian to them. The starting Gaussian has mean 1 and standard deviation 2 per feature. The committed run has 20 generations (the default is 15); its population, elite count, and games per candidate are not recorded, and the defaults are 16, 4, and 200. Final weights are rescaled so the largest is 1.0. Greedy play with them averaged 7,140.94 points. Sign note: smooth is stored as a non-positive number with a negative weight, so the term adds 0.129 per unit of total exponent difference and the search rewards rougher boards on that term. The tuner produced this sign; the other features dominate.

Training

The n-tuple network is trained by TD(0) on afterstates (game2048/train_td.py), with 1,000 games advancing in lockstep. After each move, the value of the previous afterstate moves toward the reward plus the value of the new one, with target 0 at game end. The learning rate is 0.1, split across the 48 lookups of each position, and updates are averaged per weight within a batch. The committed log ends at 64.1 minutes with 42,980 games, a mean score of 43,929, 2048 reached in 84% of games and 4096 in 32%. In the committed network, patterns 5 and 6 are transposes of patterns 3 and 4, and the symmetry sum already includes transposes, so each pair scores every board identically. In effect the table uses four distinct shapes.

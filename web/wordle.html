HOW IT THINKS
A FEEDBACK IS A PATTERN
Five tiles, three colours: 3^5 = 243 possible patterns. Each candidate answer would produce one of them for a given guess.
BITS ARE SURPRISE
H = -Σ p log₂ p over the pattern buckets. A guess that splits 2,000 words into many even buckets might give 5.5 bits; one that splits them into two buckets gives 1.
MINIMAX PLAYS SAFE
It picks the guess whose largest bucket is smallest, so the worst case is as good as possible. It can waste bits on an average turn.
THE BASELINE IS BLIND
Random consistent: any word the feedback so far allows. It uses every clue but never looks ahead, so it needs more guesses.

HOW IT WORKS

The solver keeps every answer that fits the clues so far. For each allowed guess it asks how the remaining answers would split across the 243 possible feedback patterns, then plays the guess that tells it the most. Each guess is scored from a precomputed table, so a turn is one lookup and one count per guess.

Entropy (default)

New to this? Imagine finding a hidden number with yes-or-no questions. A question that is nearly always "no" tells you little, while one that splits the possibilities evenly tells you a lot. Entropy measures the average information a guess gives, in bits.

Each candidate answer would produce one of 243 feedback patterns for a guess. If a pattern's bucket holds a share P of the candidates, the guess is worth H = -sum P log2 P bits. The solver plays the guess with the largest H.

  • Mean 3.627 guesses over all 3,568 answers, with no game lost in six guesses.
  • Best opener when every answer is possible: TARES, 6.230 bits.

Minimax

New to this? A cautious player plans for the worst case, like picking the route whose longest possible delay is shortest. Minimax picks the guess that leaves the largest group of remaining words as small as it can.

It ranks guesses by the size of the largest bucket, the worst case after the guess. Ties go to the smaller expected bucket. It optimises a different target from entropy, not a blend of the two.

  • Mean 3.739 guesses, no failures. On average it takes a little longer than entropy.

Random consistent word

New to this? Guess any word the clues still allow, chosen at random. It uses every clue, but it never asks which guess would teach the most. It is the yardstick the other two are measured against.

The pick is drawn from the answers still possible, not from the full guess list.

  • Mean 4.412 guesses. 246 of 3,568 games (6.89%) ran past six guesses.

Heuristics and their values

Expected leftAverage size of the bucket a random answer falls into, sum(bucket^2) / candidatesMinimax's tie-break

Candidate preferenceA guess that could be the answer, so it can win this turnWins ties
List orderPosition in the alphabetical guess listFinal tie-break

How these were chosen: none is tuned or learned. Each score is the objective its strategy names, and the feedback rule is fixed by the game. The tie-break order was picked so that results repeat exactly and so a guess that can win now is preferred. Bits are rounded to nine decimal places before comparing, so floating-point noise cannot reorder ties. The word lists come from the SCOWL word lists: 3,568 common answers (the small tier) and 6,748 allowed guesses. The official Wordle lists are not used, so these numbers are not directly comparable with published Wordle results.

Results: entropy and minimax lose no game in six guesses, and random loses 6.89%. The best opener that could itself be the answer is TALES (6.138 bits). TARES, the top opener, is not in the answer list.

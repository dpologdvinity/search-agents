HOW IT SOLVES
A PRESS IS A VECTOR
Pressing a light adds its column of the press matrix A. Mod 2, pressing twice cancels, so the order of presses never matters.
THE BOARD IS A SYSTEM
Each light gives one equation: the presses that touch it XOR to its lit state. Solving A x = b is Gaussian elimination mod 2.
SOME BOARDS CANNOT BE CLEARED
On 5x5 the matrix has rank 23 of 25, so only one board in four is reachable. Presses never change which class a board is in.
THE FEWEST PRESSES
The null space has dimension 2, so a solvable 5x5 board has 4 solutions. The solver returns the one with the fewest presses.

A PRESS IS A VECTOR
Pressing a light adds its column of the press matrix A. Mod 2, pressing twice cancels, so the order of presses never matters.
THE BOARD IS A SYSTEM
Each light gives one equation: the presses that touch it XOR to its lit state. Solving A x = b is Gaussian elimination mod 2.

HOW IT WORKS

There is no search and no learning here. Pressing a light is addition mod 2 (1 + 1 = 0), so a board is a linear system with one equation per light. Gaussian elimination solves that system exactly. The solver says whether a board can be cleared at all, and if it can, returns the press set with the fewest presses. HINT shows the first press of that set and SOLVE shows all of it.

Gaussian elimination mod 2

New to this? Picture a grid of clues, where each clue says whether an odd number of the switches touching one light are on. Gaussian elimination is the standard recipe for a set of clues like this. It combines clues, drops the ones that repeat, and reads off the answer one unknown at a time. Over mod 2 the only numbers are 0 and 1, so combining two clues is XOR and pressing the same light twice cancels.

The solver builds the matrix A, where row i is the cell i and its orthogonal neighbours, and writes the board as a column b. It reduces [A | b] to reduced row echelon form. Each row operation is one integer XOR. A row that reads 0 = 1 proves the board unreachable.

  • The ELIMINATION panel replays the reduction for boards up to 7x7 (the trace is cut off above that).
  • The answer is exact, so there is no tolerance or approximation to tune.

Null space and the fewest presses

New to this? Some combinations of presses cancel out completely and change nothing. Those combinations are the null space. If you know one valid answer and the list of do-nothing combinations, you can produce every valid answer. It is like having several routes to the same place and taking the one with the fewest turns.

The solver sets the free variables to 0 to get one particular solution, then XORs in every combination of the null-space basis. A solvable 5x5 board has nullity 2, so 4 solutions, and the lightest one is returned. HINT and SOLVE both use that minimum set.

  • The number of solutions is 2 to the power of the nullity.
  • Brute force would have to try all 2^25 (about 33 million) press sets on 5x5. The solver never does.

How these were chosen: nothing here is tuned or learned. The ranks and nullities are computed by the solver for each size. The board sizes (3 to 9, default 5) are limits set in lightsout/board.py. In solvable mode a board is made by pressing each cell with probability one half from a dark board, so it is solvable by construction. In any mode every light is drawn independently, and most of those boards cannot be cleared.

Measured: over 3,000 random solvable 5x5 boards, the lightest solution averages 9.9 presses, and the heaviest of the four is 5.2 presses heavier on average. A re-run with seed 1 gives 9.89 and 5.19. No committed result file covers Lights Out, so these come from re-running the code.

Checks: the tests compare the solver with brute force on all 512 boards of 3x3, and on 1,500 random 4x4 boards.

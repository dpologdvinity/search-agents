HOW IT IS SOLVED
THE DEALER
Dealer probabilities come from a recursion on the dealer's next card. Every final total, 17 to 21 or bust, gets an exact probability for each upcard.
THE PLAYER
Each hand is a state: hard total, ace, and whether it is still two cards. Hitting always adds a card, so each state depends only on larger totals. Backward induction then gives each move's exact value.
THE LEARNER
Monte Carlo control never reads the probabilities. It plays hands, keeps a running average of what each move paid, and mostly takes the best move so far, with some exploration.

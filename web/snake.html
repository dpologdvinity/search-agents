THE GENETIC LOOP
1 · PLAY
Each genome plays the same seeded boards. Fitness is apples eaten, plus a small bonus for surviving, which only breaks ties.
2 · KEEP THE BEST
The top genomes are copied unchanged, so the best result never gets lost. Tournament selection picks parents from random groups of three.
3 · CROSS AND MUTATE
Uniform crossover takes each weight from one parent or the other. Then about one weight in ten moves by a small Gaussian nudge.

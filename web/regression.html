HOW IT WORKS

A fit is the set of weights that makes the total squared error smallest. For a line or a polynomial that has a closed-form answer, the normal equations. Gradient descent reaches the same answer by walking downhill. Logistic regression swaps the squared error for log-loss, which has no closed form, so descent is the only option.

Least squares

New to this? Draw the line through the cloud of points so that the vertical gaps between the points and the line, squared and added up, are as small as possible. Squaring stops positive and negative gaps from cancelling, and it punishes one big miss more than several small ones.

With features X (one row per point, columns 1, x, x², …) and targets y, the model is ŷ = Xw. The objective is J(w) = (1/n) Σ (yi − xi·w)². Polynomial regression is linear regression on the powers of x, so the same algebra fits a curve.

The normal equations

New to this? Setting the slope of J to zero gives a system of linear equations. Solving it is one step, and no guessing is needed.

Setting ∇J = 0 gives (XᵀX) w = Xᵀy. The page solves this by Gaussian elimination. The matrix XᵀX squares the condition number of X, so when the powers of x are nearly collinear the normal equations lose digits. QR factors X = QR instead and solves R w = Qᵀy, which keeps the precision. Both give the same answer in exact arithmetic.

Gradient descent

New to this? Stand on a hill blindfolded and feel which way is downhill, then take a small step that way. Repeat. The step size is how far you move each time: too small and you crawl, too big and you overshoot the valley and climb back out.

The gradient is ∇J = (2/n) Xᵀ(Xw − y), and each step is w ← w − η ∇J. Starting from zero, the first steps fix the easy directions (the mean and the slope). High-degree powers of x are badly scaled against each other, so the valley is long and narrow and progress along it is slow. That is why a degree-10 fit creeps for hundreds of steps.

Overfitting and regularisation

New to this? A model with many knobs can memorise the noise in the training points. It looks perfect on those points and fails on new ones, the way a student who memorises last year's exam fails the new one.

Train MSE falls as the degree rises. Test MSE, measured on points the fit never saw, falls and then rises. Ridge adds λ Σ wk² to the objective (the intercept is not penalised), which shrinks the weights and smooths the curve: the solution is (XᵀX + λD) w = Xᵀy with D = diag(0, 1, …, 1). Choosing λ and the degree on held-out data is how the best model is picked.

Logistic regression and log-loss

New to this? For a yes/no label, predict a probability instead of a number. The sigmoid squashes any score into 0 to 1, and the log-loss punishes confident wrong answers heavily.

p = σ(Xw), σ(z) = 1/(1 + e−z). The log-loss is −[y log p + (1 − y) log(1 − p)], summed over points and divided by n. Its gradient is (1/n) Xᵀ(p − y), which has the same shape as the least-squares gradient, so the same descent code runs. The boundary is where p = 0.5, a straight line for degree 1 and a curve for higher degrees.

HOW IT WORKS

A ghost is a hidden Markov model: the true state (its cell and heading) changes by a known motion rule, and the sonar shows a noisy function of that state. The filter keeps the belief about the state at every turn. This page runs the exact forward recursion, or a particle filter with a chosen number of samples, in the browser. Viterbi then recovers the most likely path after a bust.

1. A hidden Markov model

New to this? You cannot see the ghost, but you know the rules it follows. A hidden Markov model is that picture: a hidden state that changes step by step with known probabilities, and an observation (here the sonar reading) that depends on the state with known noise. The filter's job is to infer the hidden state from the observations so far.

The hidden state is the ghost's open cell and its heading, so the corridor-following patrol model can work. Three motion models are offered: a random walk, a lurker that drifts toward you, and a patrol that keeps going down corridors and turns at junctions.

Each ghost gets its own filter. Every ping names the ghost it measures, so the joint belief over the ghosts factorises and the per-ghost beliefs are exact without a joint filter. Correlations between ghosts would only appear if the sonar could not tell them apart.

2. The forward algorithm

New to this? The forward algorithm keeps a probability for every possible hidden state. Each turn it does two things: predict, which pushes every probability through the motion model, and update, which multiplies each probability by how likely the ping was if the ghost were there, then rescales so they sum to 1.

This is exact, not a guess. The board has a few hundred hidden states, so every one is kept, and a turn costs a few hundred multiplications per ghost.

3. Particle filtering

New to this? Instead of tracking a probability for every state, a particle filter tracks a fixed number of guesses, particles. Each particle moves by sampling the motion model, gets a weight from the ping, and the crowd is resampled when the weights become lopsided. The fog becomes a cloud of dots.

With few particles the belief is noisy and can lose a ghost. The table below shows how quickly it approaches the exact belief as the count grows.

4. Viterbi: the most likely path

New to this? The belief answers "where is the ghost now". Viterbi answers "which whole path explains all the pings best", using the readings from before and after each turn. After a bust, the page replays that path in cyan next to the path the ghost really took in pink.

It is the same recursion as the forward pass, with a maximum in place of the sum, plus back-pointers to recover the path.

These come from the seeded benchmark (python -m ghosthunt benchmark), one core in Python. Games are 12 per row, so differences of a few turns are noise. Ghost-cell mass for the particle filter is lower than the exact filter at 10 to 50 particles: a small crowd collapses onto one corridor and loses the other, which is why those rows bust fewer games. The autopilot is a simple rule, not an optimal hunter, so the turn counts measure the belief plus this policy together. Pings give only distances, so every cell at the same distance from you looks the same; that is why the exact-cell Viterbi accuracy stays well below 1 at medium and high noise.

HOW IT WORKS

Seven agents play the same casino. Each sees only the reward of the machine it pulled, and none is trained: every run starts from scratch and learns from rewards alone. The page runs a JavaScript port of the Python agents, which reproduces the same pulls for a given seed.

The casino and regret

New to this? A slot machine pays out with a hidden chance. Pull one and you learn about that machine only. Pulling the machine that has paid best so far earns now, but a machine you have barely tried may be better. That tension is the whole problem.

The benchmark casino has 5 machines. Bernoulli machines pay 1 with a hidden probability p, otherwise 0. Gaussian machines pay their mean plus noise with sigma 0.2. Drifting machines are Bernoulli, but every 500 pulls all their probabilities are redrawn. Each mean is drawn uniformly from [0.1, 0.9], and redrawn until the best machine leads the second best by at least 0.05.

Regret is the reward given up. Each pull adds (best mean minus the mean of the machine pulled), so it measures expected loss, not the luck of one pull. Every agent on a seed faces the same outcomes: each machine's reward for each pull is rolled once.

Greedy and epsilon-greedy

New to this? Greedy always takes the machine with the best average so far. Epsilon-greedy does the same most of the time, but on a fixed share of pulls it picks a machine at random, so it keeps learning about the rest.

Greedy locks onto whichever machine looked good early. Epsilon-greedy with a fixed epsilon pulls a uniformly random machine with probability 0.1. The decaying version uses epsilon_t = min(1, K / t), where K is the number of machines, so random pulls become rarer as t grows. Greedy, both epsilon-greedy versions and UCB1 begin with a forced round: each machine is pulled once before any average is used.

UCB1 (optimism)

New to this? Give each machine the benefit of the doubt. Its score is its average plus a bonus for how little has been tried. A machine pulled only a few times gets a big bonus and is tried again, and the bonus shrinks as evidence builds up.

Each pull picks the machine with the largest mean + sigma × sqrt(2 ln t / n), where t is the pull number, n the machine's pulls so far, and sigma the reward scale: 1 for Bernoulli machines, 0.2 for Gaussian ones. This is the bound of Auer, Cesa-Bianchi and Fischer (2002).

Thompson sampling

New to this? Keep a belief about each machine's payout. Each turn, draw one plausible payout for every machine from those beliefs and pull the machine with the highest draw. A machine you are unsure about sometimes draws high, so it gets pulled. Once you know a machine well, it is pulled about as often as it is likely to be the best.

Bernoulli machines have a Beta(1 + wins, 1 + losses) posterior, starting from a uniform Beta(1, 1) prior. Gaussian machines have a normal posterior for the mean, with a N(0, 1) prior and sigma 0.2: precision = 1 + n / 0.04, mean = (sum / 0.04) / precision, standard deviation = 1 / sqrt(precision). Thompson has no forced round, so its first draws come from the prior.

EXP3 and sliding-window UCB

New to this? EXP3 keeps a score per machine, raises the scores of machines that pay, and picks machines in proportion to their scores, with a little uniform mixing so none is shut out. Sliding-window UCB is UCB1 that forgets: it counts only the last 200 pulls, so when a payout changes, the old evidence expires.

EXP3 mixes the weights into probabilities p_i = (1 − gamma) w_i / sum(w) + gamma / K. After each pull it multiplies the pulled machine's weight by exp(gamma · (reward / p_i) / K), dividing by p_i so the estimate is unbiased, and rescales the weights by their maximum. It makes no statistical assumption about the payouts. Sliding-window UCB scores each machine by its mean over the window plus sigma × sqrt(xi · ln(min(t, W)) / n_window), with W = 200 and xi = 0.6. A machine with no pulls in the window is tried first.

The Lai-Robbins floor

New to this? Lai and Robbins (1985) showed that an agent which keeps pulling the best machine most of the time must have regret of at least about c × ln T on fixed machines. The c grows when machines are close together, because close machines are hard to tell apart.

For Bernoulli arms, c = sum over suboptimal arms of gap / KL(p_i ‖ p*). For Gaussian arms with sigma 0.2, each arm contributes 2 sigma² / gap. Averaged over the benchmark's machine sets, c = 7.342 for Bernoulli (a floor of 67.6 at T = 10,000) and 1.448 for Gaussian (13.3 at T = 10,000). It is an asymptotic bound, not a guarantee at one horizon: Thompson and UCB1 on Gaussian machines, and Thompson on Bernoulli machines, finish below it at T = 10,000.

How these were chosen: The casino constants (means in [0.1, 0.9], a 0.05 gap, sigma 0.2, a 500-pull drift period, 5 machines) were set by hand so the demonstration is clear. The gap keeps the best machine identifiable. Epsilon 0.1, the decay form K / t, the UCB1 constant 2, and Thompson's uniform prior are standard choices and were not swept. EXP3's gamma is the tuning Auer et al. give for a known horizon, so it depends on T. The window of 200 and xi = 0.6 are fixed picks; the code marks xi as not tuned. No parameter sweep is committed for any agent.

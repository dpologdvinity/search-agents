EXPLORATION VS EXPLOITATION
EXPLOIT
Pull the machine with the best average so far. You earn now, but a machine you have tried only twice may still be the best one.
EXPLORE
Pull a machine you know little about. You may lose a few coins, and you learn whether it is worth returning to.
OPTIMISM
UCB1 adds a bonus that shrinks with each pull, so every machine gets tried until its bound falls below the leader.
PROBABILITY MATCHING
Thompson sampling draws each machine's payout from its posterior and pulls the best draw, so it explores exactly as long as it is unsure.
THE FLOOR
Lai and Robbins (1985) showed that no agent can beat regret of about c ln T on these machines. The dashed line in the race is that floor.

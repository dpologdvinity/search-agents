HOW IT WORKS

A neural network is a stack of simple weighted sums, each followed by a bend. Training nudges every weight a little in the direction that makes the predictions less wrong, and repeats. Everything on this page runs in JavaScript (web/js/nnlab-core.js), a port of the NumPy package that gives the same numbers for the same seed.

What a neural network is

New to this? A neural network is a function with many adjustable knobs, called weights. You give it numbers (here, where a point sits on the plane), and it gives back a guess (pink or cyan). At the start the knobs are random, so the guesses are random. Training turns the knobs until the guesses match the colours.

Here the input is the point's position, optionally widened by the features you pick. The output is one number between 0 and 1: the network's probability that the point is pink. Everything in between is a stack of layers, each a row of neurons.

The forward pass

New to this? A neuron multiplies each of its inputs by a weight, adds them up with a bias, and passes the total through a bend called an activation. A layer is a row of neurons that all read the same inputs. Chaining layers lets the network build shapes out of simple pieces.

For a layer with input a, the pre-activation is z = W a + b, and the output is f(z). The last layer uses a sigmoid, so its output p = sigmoid(z) is a probability. Hover a neuron and you see the shape it has learned: the region of the plane where it fires.

The loss

New to this? The loss is one number that says how wrong the network is. It is small when the network is confident and right, and large when it is confident and wrong. Training is just trying to make this number smaller.

The loss is binary cross-entropy: L = mean of −[y log p + (1 − y) log(1 − p)], where y is 1 for pink and 0 for cyan. It punishes confident mistakes hard. The curve on the page is log10 of the loss, averaged over the training points. The test curve uses points the network never trains on.

Backpropagation

New to this? To improve each knob, we need to know how much it affects the loss. Backpropagation works that out for every knob at once, by walking backwards from the output and passing blame down through the layers, the way a chain of cause and effect is traced.

The chain rule gives dL/dz for the output as (p − y) / batch, using the sigmoid and the cross-entropy together. Then dL/dW = (dL/dz) aᵀ, dL/db is the sum of dL/dz, and the blame moves to the layer below as dL/da = Wᵀ(dL/dz), multiplied by the activation's slope f′(z). The code in nnlab/mlp.py repeats these four steps layer by layer, and tests/test_nnlab.py checks them against finite differences.

Gradient descent and Adam

New to this? Once we know which way each knob should move, we take a small step the other way. The learning rate sets the step size. Too large and the steps overshoot; too small and training crawls. A mini-batch is a random handful of points used for one step, which is noisy but fast.

Plain descent updates each parameter as p ← p − lr · g. Adam keeps a running average of the gradient and of its square, so each parameter gets a step of about lr whatever the gradient's scale, and it is the default here. Each epoch shuffles the points and takes one step per batch.

Activations

New to this? Without a bend between layers, a stack of weighted sums is just one weighted sum, and it can only draw straight lines. The activation is that bend. It is what lets the network draw curves, and it decides how a neuron responds to its input.

tanh squashes to (−1, 1) and is centred on 0. Its slope, 1 − tanh², is 1 at 0 and falls toward 0 at the ends. ReLU is max(0, z): it is linear for positive input and off for negative, cheap to compute, and its slope is 0 or 1. Sigmoid squashes to (0, 1) but its slope is at most 0.25, so deep sigmoid stacks learn slowly. The output unit is always a sigmoid, because it gives a probability.

Overfitting and regularisation

New to this? With enough knobs, a network can memorise the training points, wiggling around each one. It then does well on those points and badly on new ones. The held-out test points show this: if the training accuracy climbs while the test accuracy stalls, the network has memorised. Two remedies are on the page: a smaller network or an L2 penalty.

L2 regularisation adds (λ / 2) Σ W² to the loss, so large weights cost something, and the gradient gains λW. The biases are left out. The test share holds points back from training. Noise blurs the points, which makes memorising harder. The defaults (no L2, no noise) are chosen to show the boundary bending freely. Raise λ or the noise to see the boundary smooth out.

Parameters and their values

ParameterDefaultWhy this value
Datasetcircles, 200 pointsA pink ring around a cyan disc cannot be split by a straight line, so the default shows what hidden layers add. 200 points keep each epoch cheap enough to run many per second.
Featuresx, yThe plain coordinates are enough for the circles, so the default network needs no extra features. The curved features change the boundary's shape, at the cost of more inputs.
Hidden layers2Two hidden layers are enough to learn the ring in the Python check (full training accuracy within 300 epochs). More layers add knobs to fit on 200 points.
Neurons per layer6Each neuron contributes one bend, and the ring needs several. Six reaches full training accuracy on the default run and still fits the diagram.
ActivationtanhCentred on 0 and smooth, so the early steps are well scaled, and its output in (−1, 1) maps directly onto the neuron colours.
Weight initGlorot uniform; He for ReLUThe weight scale keeps the signal's size about the same from layer to layer, so no layer starts saturated (flat, with no slope to learn from).
Learning rate0.03With Adam, 0.03 is fast enough to see the boundary move within seconds, and low enough that it does not jump around the ring.
Batch size16About 10 steps per epoch on the roughly 160 training points. Small batches are cheap and add sampling noise to each step, which is why the page offers 1 to full batch.
OptimiserAdam (β₁ 0.9, β₂ 0.999, ε 1e-8)The standard defaults from Kingma and Ba (2015). Adam rescales each weight's step by its own gradient history, so one learning rate works across all the weights.
L2 λ0 (off)Off so the first run shows the unregularised boundary. Try 0.01 to see the shape tighten.
Test share20%A fifth of the points are held out, so the test accuracy is measured on points the network never trained on.
Noise0Clean data first. Noise moves each point by noise × a normal draw, so the classes overlap more.
Epochs per second20Fast enough that the boundary visibly moves, slow enough to follow each change.
Seed0The points, the starting weights and the batch order all come from the seed, so the same seed replays the same run. The browser and the Python package agree on it.

Run it from the terminal: python -m nnlab train --data spiral --layers 8,8 --act tanh --epochs 500 trains the same network with the same seed and prints the loss and accuracy, then draws the boundary in text.
